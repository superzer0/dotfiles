Keep responses short, avoid unnecessary detail/elaboration.

**Why:** the user explicitly asked not to go into details after receiving a long answer to a simple
question.

**How to apply:** default to terse, direct answers. Give the core fact first; only expand if the
user asks for more. Applies generally, not just to one topic. See [[pr-docs-writing-style]] for the
written-artifact equivalent.
